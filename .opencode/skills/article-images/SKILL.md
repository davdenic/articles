# Article images

Illustrations on David's site share one look: hand-drawn ink with colored-pencil colour on white paper. They are **generated by David in his own image tool** from a prompt this skill produces. Don't hand-draw illustrations in SVG; the result never matches the style. Don't use external image connectors (MCP) either.

Division of work:

- **You (the agent):** pick the idea, write the prompt, write the alt text, post-process the file David drops in, run QA.
- **David:** runs the prompt in his image tool, attaching the style references, and picks the result.

## Style references

Attach these when generating. They define the look better than any description.

| File | What it shows |
| --- | --- |
| `src/content/articles/0008-atomic-design/hero.png` | Target density: few elements, colored-pencil hatching, sparkle ticks, handwritten title |
| `src/content/articles/0002-foundations-of-ai-assisted-software-development/redo-loop.png` | Diagram version: ink outlines, flat pastel boxes, sketched people, hand-drawn arrows |
| `src/content/articles/0019-we-love-numbers/hero.png` | Colour and texture only. Far too busy as a layout, don't copy its density |

## Style spec

- **Lines:** dark charcoal ink, confident, slightly wobbly. Rounded ends.
- **Colour:** colored-pencil hatching with visible strokes. Palette: light blue, green, orange, yellow. For diagram boxes also pastel purple and pink. No gradients, no 3D, no photorealism, no shadows.
- **Background:** white paper.
- **Density:** 3 to 6 elements, one clear focal point, lots of white space. When in doubt, remove an element.
- **Emphasis:** small yellow or orange sparkle ticks, motion lines, hand-drawn arrows.
- **People:** simple sketched figures with light cross-hatching. No real or recognisable persons.
- **Text:** handwritten lettering only, at most about 6 words in the image. The text never repeats the article title.
- **Never:** logos, brand names, watermarks, UI screenshots of real products, employer references.

## Prompt template

Fill in the brackets. Keep the fixed parts word for word so images stay consistent across articles.

```text
Hand-drawn illustration in dark charcoal ink and colored pencil on white paper,
in the style of the attached reference images.
Confident, slightly wobbly ink outlines. Colored-pencil hatching with visible
strokes in light blue, green, orange and yellow. No gradients, no 3D, no shadows,
no photorealism. Lots of white space, one clear focal point.

Scene: [one or two sentences describing the idea].
Elements (max [N]): [element 1], [element 2], [element 3].
Focal point: [element], slightly off-centre.
Emphasis: [small yellow sparkle ticks around X / dashed line showing Y].
Text in the image (handwritten, exactly as written): [none | "short label"].

Landscape, wide format, about 1.9:1. No logos, no brand names, no watermark,
no extra text.
```

Tips for David's tool:

- Ask for text **exactly as written**. Generators misspell. Regenerate rather than fix by hand.
- If the first result is busy, reply "same image, half the elements, more white space".
- Generate 2 to 4 variants and pick one. Don't iterate more than 3 rounds on one idea; change the idea instead.

`examples.md` in this folder holds prompts that shipped, what had to change, and a separate template for diagrams (boxes and arrows). Read it before writing a new prompt, and add every new prompt that ships.

## Sizes

| Use | Format | Size |
| --- | --- | --- |
| Hero / share image | `hero.png` (or `hero.jpg`) | exactly 1200 × 630 |
| Inline illustration | `.png` / `.jpg` | at least 1200 px wide, landscape |
| Plain data chart | `.svg` | `viewBox` width at least 1200, handwriting font embedded (see `AGENTS.md`) |

## Post-processing

Run on the file David saves into the article folder (macOS `sips`, no extra installs):

```bash
cd src/content/articles/NNNN-slug
# scale to 630 high, then centre-crop the hero to 1200 x 630.
# If the source is narrower than 1.9:1 (e.g. 16:9), scale with
# --resampleWidth 1200 instead, so the crop removes height, not width.
sips --resampleHeight 630 raw.png --out hero.png
sips -c 630 1200 hero.png --out hero.png
# if larger than 500 KB (qa:images warns), convert to JPEG
sips -s format jpeg -s formatOptions 82 hero.png --out hero.jpg
```

Then:

1. Look at the result (Read the image). Check the crop didn't cut the focal point or the text.
2. Reference it relatively with alt text that describes the scene, not the style: `![A cat pushing a glass of water off a table](./hero.png)`.
3. Set frontmatter `image:` to the hero file.
4. Delete `raw.*` after asking David. Never commit it.
5. Run `npm run qa`.
