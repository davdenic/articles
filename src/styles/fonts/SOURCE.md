# Fonts

## Caveat (headings)

- File: `caveat-latin-wght-normal.woff2` (variable, weight 400–700, latin subset)
- Designer: Impallari Type (Pablo Impallari)
- License: SIL Open Font License 1.1 (OFL) — free to bundle and self-host
- Source: the `@fontsource-variable/caveat` package, downloaded from jsDelivr
  (`https://cdn.jsdelivr.net/npm/@fontsource-variable/caveat/files/caveat-latin-wght-normal.woff2`)

A handwriting/script face used only for headings. Self-hosted on purpose:
no external CDN/Google Fonts request at runtime. The body reading font stays
Georgia (system serif) — see `--serif` in `global.css`.
